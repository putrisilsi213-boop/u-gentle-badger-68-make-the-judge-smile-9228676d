A program that writes one warm, surprising line about a small good thing that happened today — a bus driver holding the doors for an old man with a loaf of bread — to /output/entry.txt for the Make the Judge Smile bounty on make.fun.

## The line

> This morning the bus driver held the doors for an old man crossing with a loaf of bread under his arm — and the whole bus, strangers and all, waited like it was the most important thing in the world.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

It writes the line above to `out/entry.txt` (or `/output/entry.txt` in the grader sandbox). Pure Node 22 standard library — no network, no model calls, fully deterministic.
